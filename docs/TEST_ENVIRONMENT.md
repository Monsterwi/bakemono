# 基准测试环境

本页保留公开验收所需的硬件与测量条件。机器地址、登录账户、SSH 指纹和私有运维记录不纳入发布内容。以下信息对应 2026-10-21/22 的实测，不代表所有部署环境。

| 项目 | 实测环境 |
| --- | --- |
| 系统 | CentOS Linux 7，x86_64 |
| 内核 | `3.10.0-957.el7.x86_64` |
| CPU | 2 × Intel Xeon E5-2620 v4 @ 2.10 GHz，16 物理核 /32 逻辑核，2 个 NUMA 节点 |
| 内存 | 约 62.64 GiB，Swap 4 GiB |
| HDD | `ST4000NM0295`，7200 rpm SAS |
| SSD | `INTEL SSDSC2BB800G4`，SATA 6 Gb/s |
| 文件系统 | XFS |
| Razor 二进制 | Go 1.26.10，`CGO_ENABLED=0`，服务 `GOMAXPROCS=8` |
| HTTP 客户端 | Python 3.12.13，以及检查正文读取长度/错误的 hey |
| 网络 | 源站、服务与施压客户端同机，HTTP/1.1 loopback |

## 复现与边界

- 具体源码提交、二进制 SHA、运行参数、三轮结果及两策略各两小时长测见[完整验收报告](benchmarks/CDN_ACCEPTANCE_2026-10-21.md)。历史报告中的路径是原始证据索引，复现时自行指定结果和缓存目录。
- HDD、SSD 及不同策略分别使用新目录，压力组顺序执行。缓存文件必须保持单进程独占；不覆盖已有数据、不全局清除页缓存。
- 工作集小于主机 RAM，热磁盘路径可能命中 OS page cache。报告另列实际读盘字节达到对象大小 99% 的物理文件冷读，不把它与热缓存吞吐混为一项。
- 采样包含客户端、日志、校验及设备背景 I/O 的影响；同机结果不代表公网带宽、WAN 或 TLS/HTTP2 的生产容量。
- 当前测试内核调用 `io_uring_setup` 返回 `ENOSYS`，未进行 io_uring 测试；native AIO 也未单独验收。
- 当前 main `193fe7d` 与 ATS 10.2.1 原生/Slice 路径的 HDD/SSD 对照见[2026-10-22 报告](benchmarks/ATS_COMPARISON_2026-10-22.md)，包含三轮热读、冷合并、部分缓存、混合长尾与预取敏感性。其 I/O 和校验语义不同，不能只用吞吐倍数评价。历史 ATS 9.2.3 数据不参与本轮比较。
