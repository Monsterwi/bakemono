## 复现与边界

- [最新报告及附件](benchmarks/ATS_COMPARISON_2026-10-24.md)固定源码 `8581267`、ATS 10.2.1、二进制 SHA、三轮原值与配置。
- 本轮只测 256 KiB 热 HIT；SSD 承载缓存文件，计时阶段实际读盘为零，不代表 HDD/SSD 性能。
- 每产品使用新缓存目录，轮换顺序施压；缓存文件单进程独占，不覆盖旧缓存、不全局清页缓存。
- 同机客户端、日志、校验和后台负载均可能影响结果；未测 WAN/TLS/H2、大文件、冷读、长测或异步磁盘 I/O。
